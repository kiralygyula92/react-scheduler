# Sources of the committed assets

Every binary in `apps/docs/public/` is generated by a script in this repository from a pinned source, or drawn by hand here. Nothing is copied from a third-party site at build time, so the site builds without network access.

## Fonts

| File                               | Source                                                                                                            | License                   |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------- |
| `public/fonts/InterVariable.woff2` | Inter, from google/fonts commit `e44c4b011a820c2cbe2fd2cfa8052037d7edb571`, file `ofl/inter/Inter[opsz,wght].ttf` | SIL Open Font License 1.1 |
| `public/fonts/Inter-OFL.txt`       | The same commit, `ofl/inter/OFL.txt`                                                                              | The license text itself   |

- Built by `node scripts/build-site-font.ts`. The source TTF is verified against the SHA-256 pinned in `scripts/lib/fonts.ts` before anything is generated from it.
- Reduced to the Latin and Latin Extended code points of the Inter v20 subsets that Google Fonts publishes (docs pack `07` §1: "Latin + Latin Extended, covers ro, hu, de, fr, es, pt"), with the `opsz` axis pinned to its default and the `wght` axis kept at 100–900. Reasoning in `docs/adr/0001-toolchain.md` D7.
- Result: **132.8 kB**, SHA-256 `84a4f2ea70e1660bf599b76aea829dee280fab2636cbeca43bd9ceaec8154f0f`.
- Inter declares no Reserved Font Name, so the subset keeps the family name (OFL 1.1 §3). The license file sits next to the font, as §2 requires.

## Images

| File                            | How it is made                                                                 | Notes                                                      |
| ------------------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| `public/react-scheduler/og.png` | `node scripts/build-og-image.ts` — Playwright renders an HTML card at 1200×630 | The one static social image the docs pack allows (`01` §9) |
| `public/favicon.svg`            | Written by hand in this repository                                             | Three bars in the shell's accent token; no wordmark        |

Both use only the display name, the one-line description and the package name from the project dictionary in `AGENTS.md`, and the light-theme color tokens of the shell.

## Regenerating

```bash
node scripts/build-site-font.ts   # fonts (network: raw.githubusercontent.com, pinned commit)
node scripts/build-og-image.ts    # og.png (no network)
```

Both are idempotent: they report `unchanged` when the committed file already matches.
