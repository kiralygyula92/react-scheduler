# 10 — Package roadmap

These are milestones for the **package** repository. The documentation site's milestones come from the docs
pack. Each milestone is done only when all of its acceptance criteria pass in CI.

| Milestone | Content | Acceptance criteria |
|---|---|---|
| **M0 — Bootstrap** | Repository, TypeScript strict, ESM build, lint, test runners (Vitest, Playwright), CI; this dossier copied to `spec/feature-dossier/`; denylist scan and licence check wired in | CI green on an empty package; the denylist scan runs on every push and on PR commit messages; licence gate active; `dependencies` empty; the scenario-coverage job lists all 67 scenario IDs as "missing" |
| **M1 — Core engine** | `toMs`, `resolveEnd`, `resolveShift`, `getShiftWindows` (regular, pattern, DST-safe), `bucketItems`, `resolveLevels`, `compareByPlacement`, `computeTimelineLayout` (sweep-line), overflow grouping with merge window, `createFormatters`, `pageList`, `interpolate`, `sortOverflowItems` | `L-01`…`L-15` pass (L-13 expects the B-07 fix); all golden files equal; layout budgets met (09 §3); `core` has no React/DOM imports; 100 % branch coverage |
| **M2 — DOM engines** | Pin engine (observer, edge, epsilon, hysteresis, pause/resume, stability compensation), navigator (smooth + `scrollend`/settle correction), compact observer, reduced motion | Engine unit tests in a real browser; pin hysteresis matches `BR-L05`; timeline line matches the B-05 fix; no `scrollTop` jump when a strip first gains chips, in Chromium, Firefox and WebKit |
| **M3 — List view (parity)** | `ListView` with sections, cards, pinned strip, navigation, header signal, landing, scroll-to-top button, now marker | All `LV-*` and `BR-L*` scenarios pass (bug-tagged ones against the fixes); classic list screenshots within tolerance |
| **M4 — Timeline view (parity)** | `TimelineView` with grid, gutter, bands, lines, now line, cards, "+more", overflow dialog + table + pagination | All `TL-*` and `BR-T*` scenarios pass; classic timeline and dialog screenshots within tolerance; the timeline scroll budget is met |
| **M5 — Wrapper and states** | `<Scheduler>` view selection, `listOnlyBreakpoint`, `keepInactiveViewMounted`; detail view (default + `renderItemDetail`); empty, loading and error states; controlled/uncontrolled state for every value; events and ordering; imperative handle | Consumer-parity example (04 §10) renders the three source mounts; B-02, B-03, B-04, B-14 and B-22 fix tests pass; event-order tests pass |
| **M6 — Customization** | Parts and slots, `slotProps`, `classNames`, `styles`, render props, handler middleware, flags, item flags; tokens, `default` and `classic` presets, colour schemes, density, `unstyled` | Every part is replaceable (a test per part); middleware can cancel each interaction; axe is clean with the default preset in both schemes; classic parity is unchanged |
| **M7 — i18n, RTL, a11y, SSR** | 7 locale packs; locale-aware formatters; RTL; accessibility semantics (B-17, B-18, B-26); SSR safety | Pseudo-locale test finds no hard-coded strings; RTL screenshots mirror LTR; screen-reader text snapshots; SSR render and hydration without warnings on React 18.2 / 18.3 / 19 |
| **M8 — Performance and 1.0** | Budgets, memory test, bundle budgets, packaging checks, demos from `08`, API docs generated from types, changelog | All budgets in `09` met in CI; all 67 scenarios covered; the package tarball passes the denylist scan; 1.0.0 published under the final scoped name (see 11) |
| **M9 — v1.x** | F-40 drag-and-drop with locked/static items, F-41 persistence, F-42 feature registry, F-43 virtualization and culling, F-44 date toolbar, F-45 `timeZone`, F-46 roving focus | Per feature: its `05` rules as tests; no change to v1.0 defaults; budgets still met |
